## 0. 非材料专业读者导读

### 0.1 合金、成分与 at.%

合金是包含多种元素的金属材料。本数据集用 **at.%（原子百分比）** 表示成分：若某合金含 Fe 50 at.%、Ni 50 at.%，可直观理解为每 100 个原子中，平均约有 50 个铁原子和 50 个镍原子。

`composition(HEAL0001, "Al6.99Cr23.28…")` 就是在记录某种合金的元素及比例。一条可导入记录的成分合计应为 100 at.%；含量为 0 的元素不参与描述符计算。

### 0.2 固溶体、相结构与 XRD

**固溶体**可粗略理解为多种元素的原子共同进入同一套晶体结构，而不是完全分成各自独立的小区域。`candidate_solid_solution(X)` 表示“候选固溶体”，不是已经实验确认的固溶体结论。R1 仅用成分存在作为触发条件，是本项目用于跑通记忆闭包的简化教学规则，不能当成普遍的材料科学判据。

**相结构**描述原子主要以什么方式排列。BCC 和 FCC 是两种常见排列方式；一种合金可能同时存在多种相。XRD（X 射线衍射）像晶体结构的“指纹检测”：不同结构会在特定角度产生衍射峰。`FCC(111)`、`BCC(110)` 是峰的晶面标识，角度与标识共同帮助判断相结构。

R2 的直观含义是：同一试样同时出现 FCC(111) 和 BCC(110) 两类峰时，推出 `phase_structure(X, "BCC+FCC")`。S01 的 BCC 第二峰当前仍是占位值，不能当成已完成的实测确认。

### 0.3 smix 和 delta 在衡量什么

- **smix（理想混合熵）**：通俗地说，衡量成分中不同元素“混合程度”的一个数值。元素种类及比例不同，smix 会不同。R3 使用固定的热力学公式计算，单位为 J/(mol·K)。
- **delta（原子尺寸差异参数）**：通俗地说，衡量组成元素的原子大小有多不一致。可以想象把大小不同的球放进同一套货架，尺寸差异越大，排列通常越不整齐。delta 是一个成分派生的经验指标，不是直接测得的晶格畸变。

这两个值都能由成分计算，所以必须同时保存公式、输入成分和参数版本。仅保存一个结果数值，后续很难判断它究竟怎样算出来。

### 0.4 R1–R4 与 Horn 闭包是什么

Horn 规则可理解为“**如果前提成立，就推出结论**”。闭包推导则是把当前规则能推出的结论持续补齐。本阶段只做单层前向物化，不做递归推理。

| 规则 | 非专业解释 | 当前边界 |
|---|---|---|
| R1 | 有成分记录 → 标为固溶体候选 | 简化工程规则，不是材料成相证明 |
| R2 | 同时看到 FCC 和 BCC 特征峰 → 推出 BCC+FCC 混合相 | S01 第二峰仍为占位值 |
| R3 | 根据元素比例计算混合熵 smix | 公式固定；v2 只用于内部一致性检查 |
| R4 | 根据元素比例和原子半径计算尺寸差异 delta | 公式/半径表未标定，暂缓使用 |

每条派生结论还应带 **J（justification，辩护/血缘）**：它记录“由哪些输入事实、按哪条规则推出”。可把它理解为结论的计算过程和证据清单，后续更正输入时，系统才能找到受影响的结论。

### 0.5 参考值、派生值与“对拍”

- `ref_smix` / `ref_delta`：数据集原来携带的参考值，类似答案卡。
- `ref_smix_v2`：按公开成分和固定 R3 公式重新生成的修正版答案卡。
- `smix` / `delta`：本项目闭包实际派生的值。

**对拍**就是比较计算值与答案卡是否一致。如果计算值与 v2 一致，只能证明同一公式在两条实现路径中一致，称为**内部一致性**；如果与原参考值或独立文献样例一致，才可作为外部交叉证据。不能用自己生成的答案卡证明自己选对了公式。

### 0.6 为什么 R4 特别需要半径表和口径确认

原子半径并不是所有资料都通用的一个固定常数：金属半径、共价半径、经验半径和理论计算半径的定义不同，数值也可能不同。R4 会把这些半径代入公式，因此换一张表，结果可能明显变化。

此外还要区分小数与百分数：δ=0.019 若按比例表示，约等于 1.9%；若写成百分数则是 1.9。仅做 ×100、÷2 等整体缩放，不能证明定义正确，也不能改善计算值与原参考值的整体相关性。

因此，R4 必须先找到能复现全量参考值的公式和半径表，再决定是否修正数据；禁止仅凭“这张表常用”或“这个结果比较接近”就选定。

## 2. R1–R4 Horn 资产

Horn body/head 在 MVP 中由应用层解释，不是 mnestic 存储规则。

| rule_id | horn_body | horn_head | 类型 / 当前状态 |
|---|---|---|---|
| R1 | `composition(X, C)` | `candidate_solid_solution(X)` | join 型；规格就绪 |
| R2 | `xrd_peak(X, Θ1, "FCC(111)")` ∧ `xrd_peak(X, Θ2, "BCC(110)")` | `phase_structure(X, "BCC+FCC")` | join 型；规格就绪，S01 第二峰仍为占位实测待替换 |

## 5. 容差与后续动作

- R3：绝对误差 ≤1e-3；全量通过率目标 ≥99%，当前 86.16%。
- R4：Pearson ≥0.99 且中位相对误差 ≤5%；当前最佳 Pearson 0.731799，最佳中位相对误差 22.96%。
- 向数据集维护者索取参考 `Smix_ideal` / `lattice_distortion_parameter_delta` 的生成公式、半径表和未舍入成分精度。
- 优先核查 97 个 R3 超容差行是否共享成分版本或元素口径；在证据明确前不调整公式来迎合参考值。
- R4 阻塞解除前，不注册可用 R4、不批量写入 `delta`，不进入 Phase 1 对拍验收签署。
